# interview-questions

Банк вопросов для подготовки к собеседованию. Только Markdown: вопросы по темам и один файл с pipeline подготовки.

## С чего начать

Читайте **[PREPARATION.md](PREPARATION.md)** — расписание созвона, минимум 10 вопросов в день, livecoding.

## Структура

Каждая тема:

```text
topic/
  en/questions.md
  ru/questions.md
```

- **50 вопросов** на тему (JavaScript: **100** — 80 теории + 20 livecoding в `js/*/livecoding.md`)
- Один смысл в RU и EN, одинаковый `ID`
- Колонка **Rating**: `EPAM`, `FAANG` или оба
