# Pipeline подготовки к собеседованию

Один файл с тем, как мы готовимся. Вопросы лежат в папках тем (`html`, `css`, …) — здесь только режим и ритм.

## Расписание

| Событие | Казахстан (KZ) | Вьетнам (VN, Asia/Saigon) |
|---------|----------------|---------------------------|
| Созвон  | **19:00**      | **21:00**                 |

На созвоне: разбор слабых мест, ответы вслух, уточнение формулировок.

## Дневной минимум (теория)

- **Не меньше 10 вопросов в день** из банка.
- Порядок: сначала вопросы с рейтингом **EPAM**, затем **FAANG** по той же теме.
- Ответ формулируете сами (в репозитории только вопросы, без готовых ответов).
- Удобно отмечать разобранные ID в личных заметках.

## Трек

Выберите направление и идите по порядку базы:

1. **Frontend:** HTML → CSS → JS → TS → React → Next (плюс Vue/Nuxt или Angular по вакансии)
2. **Backend:** Computer Networks → Node.js → Express → Nest
3. **AI:** LLM (AI) после базового JS/TS
4. **System Design:** после Networks + опыта с API

## Livecoding

Банк задач пока есть только по JS: [js/ru/livecoding.md](js/ru/livecoding.md) (20 задач, `js-081`–`js-100`). Для остальных тем готовьтесь так:

1. **3–4 сессии в неделю** по 45–60 минут (или короткая сессия в дни без созвона).
2. Таймер, чистый редактор, решение **вслух** (как на интервью).
3. Фокус по треку:
   - Frontend: JS (массивы, замыкания, async), DOM, небольшой React-компонент
   - Backend: алгоритмы на JS/TS, handlers, структуры данных
   - FAANG-уклон: two pointers, hash map, recursion, BFS/DFS + сложность
4. После сессии — 5 минут: что споткнулись, какой паттерн повторить.
5. В тот же день — **10 theory-вопросов** из смежной папки (например после async → `js/`).

## Рейтинг вопросов

В таблицах вопросов колонка **Rating**:

- **EPAM** — типичные корпоративные / аутсорс-интервью
- **FAANG** — глубина, trade-offs, edge cases
- **EPAM, FAANG** — встречается в обоих форматах
